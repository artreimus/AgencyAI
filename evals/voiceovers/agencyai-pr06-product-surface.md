# agencyai-pr06-product-surface — AgencyAI is a complete local desktop product

1. AgencyAI starts from a build-selected local renderer entry, with its own window title, mark, production icons, and visibly distinct development icons. No upstream logo file is left in the renderer assets.

2. The first-run and task experience is local by design: choose a folder, connect a provider, use local skills or MCP servers, and open only the reviewed local settings. Sign-in, organizations, hosted models, remote workspaces, and cloud settings never enter this route graph.

3. AgencyAI ships seven curated offline guides for setup, providers, MCP and skills, browser and computer use, privacy, and troubleshooting. The browser and skill prompts point only to local capabilities and never steer the agent toward hosted OpenWork services.

4. The local agent receives two product-owned tools to search and read those bundled guides. A provider setup question resolves to the provider guide, while a query for OpenWork Cloud, Den, organizations, or teams returns no hosted guidance.

5. About and Licenses shows the AgencyAI build, the local-first boundary, both MIT license texts, fork source links, and factual OpenWork and OpenCode attribution. The built renderer itself rejects upstream service destinations, old logo chunks, and unreviewed user-visible OpenWork wording.

6. The actual packaged AgencyAI application launches the immutable local profile with the verified patched OpenCode runtime, native SQLite and PTY, the exact seven curated docs, both project licenses, and the reviewed local plugin closure.
