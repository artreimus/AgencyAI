# Browser and computer use

## Built-in browser

AgencyAI opens browser pages only for HTTP or HTTPS destinations requested by
the user or the active task. The model-facing browser tools can see only tabs
that AgencyAI authorized through its browser action; they cannot attach to the
application renderer.

Use the browser for navigation, form entry, screenshots, and page inspection.
Review consequential submissions before they are sent.

## Computer use

Computer use is available only when the packaged local helper is present. On
macOS it requires Accessibility and Screen Recording permissions. Grant those
permissions in System Settings only when you want the agent to interact with
desktop applications, and revoke them there at any time.
