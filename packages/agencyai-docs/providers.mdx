# Configure model providers

AgencyAI uses the providers you explicitly connect.

1. Open **Settings → AI Providers**.
2. Choose **Add provider**.
3. Select the provider and complete its API-key or OAuth flow.
4. Return to the task view and choose an available model.

Provider credentials are handled by the bundled local OpenCode runtime under
AgencyAI's isolated product data. Do not paste API keys into prompts, workspace
files, screenshots, or source control.

If a configured model disappears, open **Settings → AI Providers**, reconnect
the provider, and then reopen the model picker.
