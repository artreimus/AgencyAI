# Use MCP servers and skills

## MCP servers

Open **Settings → Extensions** to add a reviewed preset or a custom MCP server.
Remote servers receive network access only after you choose or configure them.
Local servers run the command you provide, so review commands and packages
before enabling them.

OAuth-enabled MCP servers open their own authorization flow. Disconnect or
disable a server from the same settings page when it is no longer needed.

## Skills

Skills are reusable instruction packs stored in the current workspace or the
user's local OpenCode configuration. Keep shareable behavior in version
control, but never place credentials, access tokens, or private logs in a skill.

When a task repeats, ask AgencyAI to create or update a local skill and review
the resulting `SKILL.md` before relying on it.
