# Get started with AgencyAI

AgencyAI is a local-first desktop agent. A workspace is an ordinary folder on
your computer; the app does not require a hosted account.

## Start a workspace

1. Open AgencyAI and choose **Choose a local workspace**.
2. Select an existing project folder or create a new folder.
3. Connect a model provider when the provider dialog opens.
4. Describe the first task in plain language.

AgencyAI keeps task history and workspace configuration inside its isolated
product data and the selected workspace. It does not modify another desktop
agent's configuration.

## Good first tasks

- Summarize the files in the workspace.
- Draft a document from local notes.
- Review a code change and run its focused tests.
- Clean up a CSV or create a spreadsheet.
- Open a site in the built-in browser and collect user-requested information.
