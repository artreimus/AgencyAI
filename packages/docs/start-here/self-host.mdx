---
title: "Local-first deployment"
description: "Run AgencyAI Desktop and its agent runtime entirely on one machine."
---

AgencyAI Desktop MVP is a local-first application. It does not ship a hosted
control plane, cloud accounts, organization management, remote worker
provisioning, or a Kubernetes deployment.

## What runs locally

The desktop app starts and supervises the agent runtime on the user's machine.
The selected workspace, agent state, and provider configuration remain in local
application and workspace directories. No AgencyAI account is required.

For a source checkout, use the supported local profile:

```bash
pnpm dev:local
```

Build the local desktop profile with:

```bash
pnpm build:local
```

Package an unpacked desktop build or installer with:

```bash
pnpm package:local:dir
pnpm package:local
```

## Network access

The application itself has no AgencyAI cloud dependency. The agent can still
make outbound connections when the user configures a remote model provider,
installs a connector, or authorizes a tool that uses the network.

For a fully offline setup, use a supported local model provider and avoid
network-backed tools. See [Certificate trust and proxies](/start-here/certificate-trust-and-proxies)
and [Network diagnostics](/start-here/network-diagnostics) when a corporate
network intercepts outbound TLS.

## Remote and team deployments

Remote workspaces, shared organization policy, managed identity, billing, and
cloud worker provisioning are deliberately outside the desktop MVP. Those
capabilities require a separate control-plane product and are not included in
this source tree.
